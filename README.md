## 🚀 Geliştirme

```bash
npm install
cp .env.example .env.local   # Supabase anahtarlarını gir
npm run dev                  # http://localhost:3000
```

> Gerçek ortam değişkenleri (`.env.local`) depoya dahil **değildir**; yalnızca `.env.example` şablonu vardır.
